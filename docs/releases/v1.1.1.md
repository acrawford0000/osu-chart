# osu!Chart v1.1.1

Fixes the routing type errors while keeping the existing Svelte 3 app and navigation.

## What changed

- Pinned svelte-routing to the Svelte 3 compatible 1.10.0 release.
- Corrected the location-store type used by the sidebar, preserving active-page highlighting.
- Added Svelte type checking to the Windows release workflow to catch routing regressions.
- Pinned the release build to Go 1.23.12 for compatibility with Wails 2.10.2.

## Download

- Run `osu-chart-v1.1.1-windows-amd64.exe`, or extract `osu-chart-v1.1.1-windows-amd64.zip` and run `osu-chart.exe`.
- `SHA256SUMS.txt` contains checksums for both downloads.
- Windows x64 and Microsoft Edge WebView2 Runtime are required. The Microsoft WebView2 bootstrap installer is embedded for systems without the runtime.
- Go, Node.js, and Wails are not needed to run the app. The executable is unsigned.

Existing credentials continue to work. This package contains no API credentials.

## Verification

Svelte checking passes with zero errors or warnings; all 18 frontend tests, Go tests, and the production frontend build pass. Players, Chart, Settings, Contact, sidebar highlighting, and refreshing the Contact route were checked in the desktop app.
