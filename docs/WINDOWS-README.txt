osu!Chart 1.1.0 - Windows x64

Run osu-chart.exe. You do not need Go, Node.js, npm, or Wails installed.
Microsoft Edge WebView2 Runtime is required. Its Microsoft bootstrap installer
is embedded in this build for computers where the runtime is missing.

Open Settings to enter your osu! OAuth Client ID and Client Secret, then add
players and use Chart to compare their recorded history. Historical coverage
depends on the snapshots available from osu!track.

Credentials are stored in:
  %APPDATA%\osu-chart\osu_auth_credentials.json

This package contains no API credentials or player debug dumps.
This Windows build is not code signed.

Source, screenshots, and documentation:
  https://github.com/acrawford0000/osu-chart
